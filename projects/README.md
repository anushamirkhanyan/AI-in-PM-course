# Course Projects

Each course project/exercise gets its own folder here, e.g.:

```
projects/
  01-status-report-generator/
  02-risk-register-agent/
  03-meeting-agenda-skill/
```

Give each project folder a short `README.md` describing:

- **Goal** — what the exercise is practicing (e.g. building a skill, a
  subagent, a small workflow)
- **What's in here** — the files/deliverables for this exercise
- **Notes** — anything learned or worth remembering for next time

Nothing needs to go here yet — this folder is just the landing spot for
projects as you build them through the course.
